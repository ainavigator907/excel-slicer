# Excel Slicer ― 列で選んでファイル分割

*[English version](README.en.md)*

1つのExcelファイルを、指定した列（エリア・担当者・部署など）の内容ごとに分割し、別々のファイルとして自動保存するWindows用ツールです。

読み込んだExcelの中身をツール内にそのまま表示するので、**列見出しや行番号をクリックするだけ**で設定できます。関数もマクロも不要です。

<br>

## ダウンロード

**▶ [最新版をダウンロード（Releases）](../../releases/latest)**

用途に合わせて2種類あります。どちらも中身は同じツールです。

| | ファイル | 特徴 |
|---|---|---|
| **単体exe版** | `ExcelSlicer_v4.exe` | インストール不要。ダウンロードしてダブルクリックするだけ。起動は約2〜3秒 |
| **インストーラー版** | `ExcelSlicer_v4_setup.exe` | インストールして使う。**起動が約1秒**と速い。起動の待ち時間が気になる方はこちら |

単体exe版は起動のたびに中身を一時フォルダに展開するため、どうしても数秒かかります。
インストーラー版は展開が起きないぶん速く起動します。

- 対応OS: Windows 10 / 11（64bit）
- Excelがインストールされていない環境でも動作します
- インストーラー版は**管理者権限なし**でインストールできます
- 保存した「分割方法」などの設定は両方の版で共有されます

> **初回起動時の警告について**
> 個人が作成した署名なしのツールのため、初回起動時に「WindowsによってPCが保護されました」という青い画面が出ることがあります。
> 画面の「詳細情報」をクリック →「実行」を選択してください。

<br>

## できること

| 機能 | 内容 |
|---|---|
| 列の値ごとにファイル分割 | 指定した列の内容ごとに、Excelファイルを自動で切り分けます |
| 書式・数式をそのまま維持 | セルの色や罫線、数式を保ったまま出力します |
| 画面クリックだけで設定 | Excelと同じ見た目のグリッドを見ながら、列・行をクリックして指定します |
| シートごとの設定 | ブック内の複数シートに、それぞれ別の分割設定ができます |
| 分割方法の保存 | よく使う設定に名前を付けて保存し、次回はプルダウンで呼び出せます |
| 日本語 / English | 画面右上の「language」ボタンで表示言語を切り替えられます（再起動不要） |
| 保存ファイル名の並び方 | 3種類のパターンから選べます（既定は従来どおり） |

<br>

## 基本的な使い方

1. `ExcelSlicer_v4.exe`（またはインストールした Excel Slicer）をダブルクリックして起動します
2. 分割したいExcelファイルを、画面上部の**ドラッグ＆ドロップ**エリアに入れる（または点線の枠内をクリックしてファイルを選択）
3. 読み込むと、シートの中身がExcelと同じ見た目でツール内に表示されます
4. 画面中央の**モード切替ボタン**で設定したい項目を選び、グリッドの列見出し（A, B, C…）や行番号をクリックします
5. 画面下部の「出力するデータを選択」で、書き出したいものにチェックを入れます
6. 「保存先変更...」で出力先を指定し、「**分割して保存実行**」ボタンを押します

<br>

## モード切替ボタン（クリックで設定する4つの項目）

### 🔑 分割キー列
列見出しをクリックすると、その列がファイル分割の基準になります（緑色で表示）。もう一度クリックで解除されます。
基本は1列だけ選びます。1つのシート内に表が横に複数並んでいる特殊なケースのみ、最大5列まで選べます。

### 🗑 削除列
列見出しをクリックすると、その列が出力ファイルから削除されます（赤色＋取り消し線で表示）。離れた列を個別に選ぶこともできます。
列見出しを**右クリック**すると「この列以降をまとめて削除」も選べます（末尾の不要な列をまとめて消したいとき）。

### 📏 データ開始行
行番号をクリックすると、その行が「データの開始行」になります（行番号が青色で表示）。
それより上の行は見出しとして扱われ、分割されずにすべての出力ファイルに残ります。もう一度クリックで自動検出に戻ります。指定しない場合は自動で判定します。

### 🚫 分割対象外の行
行番号をクリックすると、その行が分割の対象から外れます（黄色で表示）。
対象外にした行は絞り込みの影響を受けず、どの分割ファイルにも元のまま残ります。表の下の注記行や、特定の行だけを常に残したいときに使います。
また、対象外にした行の値は「出力するデータを選択」の一覧にも出てこなくなります。

> いずれの操作も、マウスの右クリックメニューから同じことができます。

<br>

## シートの選択（シートタブ）

グリッドのすぐ下に、ブック内のすべてのシートがタブで並びます。
タブをクリックするとそのシートの中身に切り替わり、**シートごとに別々の設定**ができます。

分割キー列を選ぶと、そのシートは自動的に出力対象になり、タブに「✓」が付きます。右側の「このシートを分割対象にする」チェックボックスでも切り替えられます。

※ 出力対象になっていないシートは、分割後のファイルからは削除されます。

<br>

## 分割方法の保存

よく使う設定は「**分割方法を保存**」ボタンで名前を付けて保存できます。
次回以降は「分割方法」のプルダウンから選ぶだけで、同じ設定を呼び出せます。（以前のバージョンで保存した設定もそのまま読み込めます）

<br>

## 保存ファイル名の並び方

「ファイル名:」のプルダウンから、出力ファイル名のパターンを選べます。

| パターン | 例（分割キーが「東京」、元ファイルが「売上.xlsx」のとき） |
|---|---|
| 【キー】ファイル名（既定） | `【東京】売上.xlsx` |
| ファイル名_キー | `売上_東京.xlsx` |
| ファイル名（キー） | `売上（東京）.xlsx` |

既定は従来どおりの並び方なので、変更しなければ今までと同じファイル名で出力されます。

<br>

## 表示言語の切り替え

画面右上の**「language」ボタン**を押すと、**日本語 / English** を選べます（普段は日本語のまま使う人がほとんどなので、プルダウンではなくボタンにしてあります）。切り替えは即座に反映され、再起動は不要です。
選んだ言語は次回起動時にも引き継がれます。初回起動時は Windows の表示言語に合わせて自動で選ばれます。

<br>

## よくあるご質問

**Q. 分割後のファイルはどのような状態になりますか？**
A. 指定した分割キー列に該当しないデータ行は削除され、開いたときに一番左上（A1セル）が見える状態で保存されます。「合計」や「小計」などの行、および「分割対象外の行」に指定した行は残ります。書式や数式もそのまま引き継がれます。

**Q. 表の途中の列を削除したら、数式がおかしくなりました。**
A. 表の途中（末尾以外）の列を削除すると、その列を参照していた数式や、削除位置をまたぐ結合セルが崩れる場合があります。この指定をしたときは画面に警告が出ますので、書き出したファイルを必ずご確認ください。末尾の列をまとめて削除する場合（右クリックの「この列以降をまとめて削除」）は、この問題は起きません。

**Q. 行数の多いシートで、画面に一部の行しか表示されません。**
A. 画面表示は先頭5000行までですが、**分割処理はシートの全行が対象**になります。
